# 空账单卡片快捷记账设计

## 背景

账单没有消费时，页面会显示“＋ / 还没有消费 / 点右上角‘记一笔’”空状态卡片。目前卡片中的圆形“＋”只是普通文本，没有点击事件，因此用户点击后没有反应；右上角“＋记一笔”按钮则正确调用 `openNewExpense`。

## 设计决定

- 保持空状态卡片现有视觉布局不变。
- 将整张空状态卡片绑定到现有 `openNewExpense` 方法。
- 点击圆形“＋”、标题、说明文字或卡片空白区域时，都打开同一个“记一笔”编辑器。
- 为卡片增加按钮语义和清晰的无障碍标签。
- 不增加新的业务方法，不复制编辑器逻辑。

## 交互与错误处理

空状态卡片与右上角按钮共用 `openNewExpense`，因此沿用现有的草稿状态、编辑器初始化和错误处理。账单已有消费时，空状态卡片不会渲染，不影响消费列表的编辑行为。

## 测试与验收

1. 先增加页面结构回归测试，要求空状态卡片绑定 `openNewExpense`，并具备按钮角色和无障碍标签；确认测试在旧代码上失败。
2. 只修改空状态卡片模板，使回归测试通过。
3. 运行完整自动化测试。
4. 在微信开发者工具中新建空账单，分别点击卡片中的“＋”和卡片其他区域，确认都会打开“记一笔”编辑器。

## 范围

本次不调整分账算法、数据结构、卡片视觉样式或已有消费列表。
